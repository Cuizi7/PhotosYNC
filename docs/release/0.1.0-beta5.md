# PhotosYNC 0.1.0 beta5

PhotosYNC 0.1.0 beta5 (build 5), macOS 13+, Universal arm64/x86_64.
本包为本地 ad-hoc 签名版本，未作 Developer ID 签名或公证。

## 修复

1. 完整扫描后，来源中已删除的 JPG 等文件按正常删除处理：只清理安全的待处理记录，并撤销依赖该记录的重复跳过证据。保留已导入历史、提交中记录及结果未确认的记录；源目录和 Photos 资产均不被删除。
2. 对系统媒体接口无法解析的 MPG，继续保留明确的文件级读取失败，不转码，也不把该文件伪装成正常跳过。诊断日志补充 AVFoundation 外层与底层错误域及代码，便于定位。
3. 菜单中逐文件查看失败详情仍待设计有界的展示方式，已在源码标记 TODO。本版沿用文件失败计数与现有来源问题提示。

## 验证记录

发布脚本从干净的 main 提交归档源码，在同一归档运行完整 XCTest、合成数据工具测试和 continuation-race 回归，再构建并核验 Universal Release app、嵌套签名、图标、DMG 和 SHA256。确切提交、测试数量、工具链和校验值见包内 `PhotosYNC.provenance`、`validation/validation.json` 与 `SHA256SUMS`。

修复提交 `44e9076` 的开发验收通过：258 XCTest、21 个工具测试及 continuation-race 回归。发布验收结果以本包附带的证据为准。

## 边界与未验证项

本版未增加转码或新的媒体读取路径。受影响的真实 MPG 经 AVFoundation 读取失败；未对该文件执行真实 PhotoKit 直接提交试验，因此不声称已证明 PhotoKit 也无法导入。真实 Photos 导入、原生菜单交互、macOS 13/14 实机、系统通知和 Developer ID/公证仍需独立验收。本次打包不安装或启动正在使用的 PhotosYNC，也不修改生产数据库或来源文件。

## 构建与分发

输出目录为 `outputs/releases/0.1.0-beta5/`，包含 `PhotosYNC.app`、`PhotosYNC-0.1.0-beta5.dmg`、`RELEASE-NOTES.md`、`PhotosYNC.provenance`、验证证据和 `SHA256SUMS`。既有 beta 产物保持原样。
