# PhotosYNC 0.2.9

版本：0.2.9 stable（build 17）。最低 macOS 13，arm64/x86_64 Universal。确切发行源码、验证结果及产物身份由本次 `PhotosYNC.provenance` 与 `SHA256SUMS` 绑定。

## 本版改进

- **与 app icon 呼应的状态图标。** 菜单栏、菜单标题和设置共用 S 丝带主体，右下放大折页区分别显示完成、同步双箭头、暂停、沙漏、异常和未配置标记。透明折缝及镂空让系统适配浅色、深色外观。
- **未挂载目录置灰。** 已启用来源当前根目录确诊卷未挂载时显示灰色完整 S，不加状态折页。普通排队等待、其他目录或文件问题仍显示状态标记；全局阻断错误和用户暂停保持优先。
- **按选定设计稿等比还原。** 原生矢量图像为 18 × 20 pt，使用统一缩放，保留稿中的主体、折页和粗状态符号。全局等待和错误标题为“等待中”与“同步异常”，具体恢复、重试和核对说明保留。

选定设计与实现规则见 `Design/Icons/MenuBar/`。本版沿用 0.2.8 的来源可用性、文件问题计数和恢复规则；未改变同步调度、Photos 提交与媒体读取逻辑。

## 升级与数据库

沿用 **schema v10**，本版不新增迁移、不清理生产数据。已有任务、成功导入历史、分析成果、未知提交保护、模型和 0.98 判重阈值保持既有规则，来源只读与 Photos 仅新增边界不变。

打包不会安装或启动应用，也不会备份或迁移生产数据。schema v9 或更早的应用不能读取升级后的数据库；不要通过恢复旧数据库丢失后续成功导入证据。

## 验证与本地分发

图标开发快照已通过七态等高轮廓对照、1×/2×模板检查、浅深色离屏菜单与设置回归及独立视觉复核。轮廓测试不横向拉伸参考图；人工逐态检查补充符号语义和可读性核对。

正式包从合并后 main 的干净确切提交归档，执行完整无过滤 XCTest、Tools、模型/资源门槛、两组受控续体 GREEN/预期 RED，以及正常 Universal Release 构建、逐层签名、DMG 和校验值检查；实际通过结果以随包证据为准。

本版为图标与文案调整，明确使用 **release** 规模档：20 万表示＋10 万成功历史，含既有性能阈值、大媒体与 60 秒空闲/恢复检查，不声称完成 full 四档。

未新增真实 Photos/iCloud、真实挂载断开/恢复、系统菜单选中态、物理交互、VoiceOver、macOS 13/14 或 Intel 实机验收；离屏图不替代这些边界。历史系统证据不写成本包的新实测。

本地交付包含 `PhotosYNC.app`、`PhotosYNC-0.2.9.dmg`、发行说明、provenance、完整验收证据与 `SHA256SUMS`。采用 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证；本次不执行远端发布或安装。
