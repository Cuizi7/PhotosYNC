# PhotosYNC 0.2.3

版本配置：0.2.3 stable（build 11）。最低 macOS 13，arm64/x86_64 Universal。本页是发行准备说明；最终源码提交、完整验收结果和产物校验值以确切 main 归档生成的 `PhotosYNC.provenance`、validation 和 `SHA256SUMS` 为准，不能由版本配置或历史日志推断已经发布。

## 本版改进

- **重试从实际失败时刻计时。** 图库分析沿用 5/15/30/60 秒退避；读取或模型工作耗时不再使期限错误地从较早的批次时间起算。模型不可用仍等待 60 秒。每轮的到期筛选时间固定，持久化期限继续使用墙上时钟；系统时间回拨可能延后重试。
- **有限批次公平推进。** 每批最多尝试 16 个任务，达到 1 秒单调时钟预算后停止接纳下一项，已开始的工作正常结束。轮转游标让新任务和到期重试都有机会推进，由后续运行时 tick 继续；已确认内容未变的元数据更新不会重置轮转、任务身份或失败退避。
- **读取容量不足时统一等待。** 接纳检查包含实际请求、清理工作和消费者仍持有的共享图像预算。容量忙时不为其他任务制造失败、增加重试或移除指纹。逻辑超时只记录自身任务的失败并保留物理所有者；真实完成、清理和 lease 释放后，后续 tick 才继续。等待物理完成达到 60 个单调时钟秒时显示汇总等待状态，不强制释放、不创建替代读取器。系统请求永不回调时，不保证自动恢复。
- **有界匿名因果日志。** 同一运行内关联历史回放/实时变更、保守失效、实际 ready→pending 数、任务尝试、失败期限及请求/lease 生命周期。最多 8 个固定采样资产有受限详情，其余使用汇总；中性事件和未变的轮询状态合并并记录抑制数。新增关联字段使用运行内匿名标识，不输出原始资产 ID、历史 token、路径、图像或 EXIF。既有系统错误及来源诊断仍可能包含操作元数据，分享日志前须自行检查。

## 行为与升级边界

本版没有解决或确认“历史反复保守失效”的根因；诊断关联不构成 token 相等、历史覆盖或内容连续性的额外证明。中性日志量有合成测试证据，但任意真实变更、错误文本及既有日志流没有全局限流，不能承诺整份日志在所有负载下保留固定时长。

继续使用 schema v8，无新增迁移、数据库清理或历史重写。0.2.2 升级不需要新迁移；成功导入历史与未知提交保护保留。模型、0.98 阈值、媒体范围、Photos 资源读取方式、权限、bundle identity 及来源只读/Photos 仅新增边界不变。不会将离线 iCloud 资源视为已完成，也不承诺 iCloud-only 读取或其他设备云端传播完成。

首次启动前，正常退出 PhotosYNC，并备份完整 `~/Library/Application Support/PhotoSync/`，包括 SQLite WAL/SHM 等配套文件。从更旧版本升级仍遵循既有 v3–v8 迁移规则；旧应用不能直接打开升级后的库，恢复旧库可能丢失后续成功证据并造成重复新增。既有模型、资源、升级和降级边界见 [0.2.2 发行说明](0.2.2.md)及 [0.2.1 发行说明](0.2.1.md)。打包不读取、备份或迁移生产数据。

## 验证与分发限制

实现阶段采用 fake Photos、自制媒体、UUID 临时数据库、受控回调和独立墙上/单调时钟测试，覆盖期限、有限批次、公平轮转、容量竞争、超时后晚到完成、lease 持有及暂停/上下文变化。新增等待文案有合成原生 NSHostingView 证据；这不能替代真实菜单、输入、焦点或 VoiceOver 验收。批准范围与验收契约见[规格](../superpowers/specs/2026-10-16-index-recovery-023.md)和[实施计划](../superpowers/plans/2026-10-16-index-recovery-023.md)。聚焦测试不是完整验收结论；独立集成评审与候选完整 `scripts/validate.py` 是尚需完成的发布门槛。

正式包须从确切干净 main 提交归档，在同一归档内重新完整验收，并核验版本、模型资源、Universal app/Core、图标、逐层签名、DMG 和校验值，目标为 `outputs/releases/0.2.3/`。已有路径不覆盖，旧包、归档和证据保留。最终状态以该包所附 provenance/validation 为准。

本轮未新增真实 Photos、生产 App/数据库/来源/设置或实际网络/iCloud 实测。既有真实验证及缺口见[历史 closeout](2026-10-13-final-real-qa-closeout.md)；macOS 13 与 Intel 实机本轮不执行，Universal 构建不能替代硬件运行。无终止回调的真实系统时序及任意负载下整份日志保留时长未被证明。

分发沿用本地 ad-hoc 签名，不等于 Developer ID 签名、公证、stapling 或 Gatekeeper 验收。安装和生产启动由用户随后执行；本轮准备、验收或打包均不代表已安装、启动或实测系统权限。
