# PhotosYNC 0.3.0 beta3

版本：0.3.0 beta3（build 20），最低 macOS 13，Universal arm64/x86_64。本次为本地 ad-hoc 签名 App／DMG；确切源码和验收结果以随包 `PhotosYNC.provenance`、`validation/` 与 `SHA256SUMS` 为准。

## 本版修复

- 视觉索引与 Live Photo 各显示一行说明和自己的进度条；已知与未知总量的轨道同宽、5pt 高、纯色无渐变。等待及暂停保留数量与说明入口，停止动画。任务说明分别解释历史计数、iCloud 流量、续跑和旧单项影响。
- 正常排队与批次切换保持任务活动状态；无来源的图库配对任务不再误报需要配置。真实重试期限、资源占用和未知写入仍如实等待或阻断。
- 读取原件遇到 Photos 通知分类时有界等待并重新验证；元数据后的新分类竞争立即延后，不再设置全 Live Photo 队列 60 秒冷却。精确资源变化、权限或未知覆盖仍拒绝旧结果。
- 确定性解码超限停止同修订自动重读；“立即扫描”或精确输入变化才重新尝试。健康表示继续发布，需处理项单独提示。
- 跳过空消费和状态查询中的额外 Photos 工作，修复来源停用后旧配对预留无法释放，并增加匿名阶段耗时、原因及活动汇总日志。

保留原始 Live Photo、声音、一次性全库识别完成标记、成功历史和 schema v11。来源只读，只有已验证完整目标才可替代精确旧单项；未知 Photos 写入继续阻断新提交。

## 验收与边界

开发阶段已完成深度评审、受控竞态回归、完整 full 验收及原生 UI 布局检查，详情见[修复验收记录](../validation/2026-10-22-task-progress-repair.md)。发布从 squash 合并后的 main 确切提交归档执行：

```sh
scripts/package-release.sh --scale-profile full
```

发布门槛包含完整 XCTest、Tools、10 万／15 万／20 万表示与 20 万表示＋10 万成功历史四档、模型和资源检查、两组续体竞态，以及 Universal Release、版本、嵌套签名、图标、DMG 和校验值核验。实际通过状态及数量以本包新生成的证据为准。

原生布局、任务说明和程序点击弹层已检查；真实系统菜单 hover、Escape、焦点和玻璃材质尚未完成实机验收。没有重测真实 iCloud 下载吞吐、Photos 提交、macOS 13/14 或 Intel 实机。未做 Developer ID 签名或 Apple 公证。

独立目标目录：`outputs/releases/0.3.0-beta3/`，存在时拒绝覆盖。本次不安装、启动生产 App 或公开远端发布。
