An ordinary Git blob must contain only its pointer. `package-release.sh` archives the exact clean commit with `GIT_LFS_SKIP_SMUDGE=1` (preventing archive-time filter hydration/network access), calls the archived `scripts/advanced-dedup/release.py` to resolve that commit's pointer from the repository's local LFS object store, verifies size/SHA and the complete package identity, then validates/builds that archive. Missing, corrupt or pointer-only weights fail; no implicit fetch/upload occurs. The built framework is checked again and compared with archive resource evidence before signing. Unexpected images, vectors, research JSON, scripts or browser prototypes are rejected from the App. `resources.json` and provenance bind the copied bytes.

Install Git LFS using its official distribution, then use `git lfs install --local --skip-repo` to preserve hooks and global configuration. Hydrate this checkout with explicitly authorized `git lfs fetch` / `git lfs checkout` when its local object is absent.
