# PhotosYNC 0.3.0 beta5

版本：0.3.0 beta5（build 22），最低 macOS 13，Universal arm64/x86_64。本地 ad-hoc 签名 App／DMG；实际源码、验证结果和校验值以随包 `PhotosYNC.provenance`、`validation/`、`SHA256SUMS` 为准。

## 本版修复

- 来源状态刷新保留已有视觉索引及 Live Photo 状态。较新的进度仍在读取时，较旧但完整的发布仍可供界面使用；已完成的新发布不会被旧结果覆盖。未完成的任务行不再因临时空快照消失。
- Live Photo 后台每批最多处理 16 项，每项之间让出执行权；有实际推进时自动继续下一批，不再等待界面每秒轮询。暂停、授权撤回、资源排空、读取延后和无进展时停止启动后续项，仍保持单个 worker 和既有 Photos 写入保护。
- 新增匿名任务状态转变、每项处理及批次耗时、退出原因诊断；界面按原有节奏刷新，重复空闲状态合并记录。

不改变界面布局和文案、schema v11、512 MiB 资源预算、10 秒普通视频筛选、未核实目标准入、原资源及音轨保留和源目录只读规则。

## 验证与分发

开发证据见[beta5 验证记录](../validation/2026-10-23-beta5-runtime-progress.md)。发布从 squash 合并后的本地 main 确切提交归档运行 `scripts/package-release.sh --scale-profile full`：完整 XCTest、Tools、四档规模、两组续体竞争，以及版本、Universal、图标、签名、DMG、源码清单和校验值核验。仅随包新生成的通过证据确认发布成功。

UI 验证使用隔离模型和原生离屏渲染，不访问真实图库；不等同于系统菜单交互、物理 hover 或旧系统实机验收。本版不改 PhotoKit 读写实现，不重新执行真实图库写入测试。实际 iCloud 下载和安装后吞吐仍需运行观察，测试不能承诺实际每分钟处理数量。

交付目录 `outputs/releases/0.3.0-beta5/`，已有目录拒绝覆盖。未执行生产 App 安装/重启、远端发布、Developer ID 签名或公证。
