# PhotosYNC 0.1.0 beta

Frozen beta, build 1. Minimum macOS 13; Universal app for Apple Silicon and Intel.

## Included

- Native menu-bar app, status indicator, compact settings and opt-in login launch.
- Multiple read-only filesystem sources; scan at startup and every 30 minutes.
- Additions to the System Photo Library only; conservative filename/metadata duplicate detection.
- Persistent SQLite import history; removal of source configurations retains history and never deletes media.
- Bounded slow-source I/O and directory recovery handling.
- Approved D2 icon, with native pale gradient and transparent S foreground. Icon Composer resources and a macOS compatibility ICNS are compiled by Xcode.

No sync-engine or database behavior changes were introduced by the beta freeze. App version is 0.1.0, build 1; the beta channel is shown in Settings. Bundle ID and Application Support/PhotoSync data location remain unchanged.

## Install and data

Open PhotosYNC-0.1.0-beta.dmg and drag PhotosYNC.app to Applications. Quit an older PhotosYNC before replacing its installation. This artifact has an ad-hoc signature; it is not Developer ID signed or notarized and is not a public Gatekeeper-approved release.

Existing configuration/history lives at ~/Library/Application Support/PhotoSync/sync.sqlite. Replacing the application does not reset it. Do not remove the database to troubleshoot: it contains successful-import history that prevents reimporting assets. Automatic database backup is not implemented. For a manual consistent backup, quit PhotosYNC and preserve the entire Application Support/PhotoSync directory.

## Validation and remaining limits

The freeze checks a Universal Release build, compiled icon and version metadata, automatic core tests, nested ad-hoc signatures, and DMG integrity. Actual GUI/Photos acceptance from earlier source snapshots is documented in Design/Validation.md and the dated release reports; it is not rerun against the personal Photos library for this packaging-only change. A macOS 13 declaration or Intel build is not a new macOS 13 runtime acceptance.

Still outside this beta's completed acceptance or functionality:

- Developer ID signing, notarization and public-distribution Gatekeeper acceptance.
- Complete login/logout, notification, sleep/wake, keyboard/VoiceOver and every supported macOS combination.
- Robust mount identity detection when a disconnected share leaves a normal empty directory; see 2026-09-15-network-recovery-plan.md for the next-version plan. No automatic mount or credentials storage.
- Non-interruptible I/O may exhaust bounded worker slots and require restart.
- Photos may expose changed original filenames for identical-content resources. With a lost local database, metadata-only matching cannot guarantee no duplicate import.
- Deletion/overwrite sync, media hashing, precise duplicate adjudication and Live Photo pairing remain future work.

## Rebuild and provenance

From a clean committed checkout, run scripts/package-release.sh. It refuses to overwrite an existing version directory, builds from source into a new work directory, signs nested code, verifies both architectures, creates the DMG and emits provenance plus SHA256SUMS. It does not launch PhotosYNC or change production data.
