# PhotosYNC 0.3.0 beta4

版本：0.3.0 beta4（build 21），最低 macOS 13，Universal arm64/x86_64。本地 ad-hoc 签名 App／DMG；实际源码、验证结果和校验值以随包 `PhotosYNC.provenance`、`validation/`、`SHA256SUMS` 为准。

## 本版修复

- 超过 10 秒的普通视频跳过 Live Photo 识别，仍正常判重和导入为视频。恰好 10 秒、未知/无效时长继续识别；Photos 已标记为 Live Photo 或当前已有精确配对身份的资源不受此规则限制。这是应用的筛选规则，可能排除尚未识别的第三方长 Live Photo，并非 Apple 格式上限。
- 图库预筛选只读取轻量时长属性；旧未完成普通视频分批刷新描述后应用新规则，包括过去因读取超限而暂停的项目。不重启首次全库清点，不重新分析已完成结果。
- 未解决的配对问题不会随其他任务开始执行而消失。已删除关联项目保持停止补齐，不再误报需要重试；资源读取超限给出具体说明，未确认身份的内容不再笼统称为 Live Photo。
- 补齐任务在进入执行状态、读取 Photos 快照之前检查前置条件；识别产生新事实时仍可发现配对。日志将有阶段推进、无进展和失败分开记录。

- 资源描述未变的通知不再使 Live Photo 识别结果作废重读；真实变化、未知与删除仍保守处理。完整增量通知按变化项查询，非增量保留整库恢复。
- 补充匿名读取的首包、交付、写入、完成回调、排空与字节日志；来源扫描完成会唤醒配对，旧进度发布不会覆盖新摘要。

保持每任务一行及同宽纯色进度条、固定默认配对行为、512 MiB 资源预算、schema v11、原资源和音轨保留、源只读、已验证目标才替代旧单项以及未知写入保护。
