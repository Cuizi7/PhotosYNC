# PhotosYNC 0.1.0

PhotosYNC 0.1.0 正式版（build 6），支持 macOS 13+，包含 arm64/x86_64 Universal app。此包供本地交付，使用 ad-hoc 签名；未进行 Developer ID 签名或公证。

## 本次发布

同步代码沿用 beta5 已验证的版本；本次更新正式版渠道、构建号、发布说明和 changelog。源目录仍严格只读，Photos 仍仅新增资产。完整功能与已知边界见随包提供的 `CHANGELOG.md`。

## 验证与来源

`scripts/package-release.sh` 从干净的发布提交归档源码，在同一归档内运行完整 XCTest、工具测试和 continuation-race 回归；随后构建 Universal Release app，并核验图标、嵌套签名、DMG 与 SHA256。确切源码提交、测试数量及校验结果见包内 `PhotosYNC.provenance`、`validation/validation.json` 和 `SHA256SUMS`。

本次仅进行自动验收和本地打包；未安装或启动此构建，也未执行新的真实 Photos 导入、macOS 13/14 实机交互、Developer ID 签名或公证。现有 beta 包及运行数据保持原样。

## 使用前须知

PhotosYNC 按完整文件名精确判重。不同文件名的相同照片可能再次导入；HEIC/MOV 实况照片文件不会合并为一个资产。对含改名备份或重复副本的来源，请先按目录筛选。由于此包采用 ad-hoc 签名，从 beta 构建换到正式版时 macOS 可能要求重新授予照片权限。

输出目录：`outputs/releases/0.1.0/`，包含 `PhotosYNC.app`、`PhotosYNC-0.1.0.dmg`、`RELEASE-NOTES.md`、`CHANGELOG.md`、验证证据、`PhotosYNC.provenance` 与 `SHA256SUMS`。
