# PhotosYNC 0.3.0 beta6

版本：0.3.0 beta6（build 23），最低 macOS 13，Universal arm64/x86_64。本地 ad-hoc 签名 App／DMG；实际源码、验证结果和校验值以随包 `PhotosYNC.provenance`、`validation/`、`SHA256SUMS` 为准。

## 本版修复

- 通知分类短暂阻塞识别时，保留一份已读完的原资源及一个资产的部分解析结果，恢复后继续处理，避免重复读取和解析。每份保留最多 30 秒，仍受 512 MiB 总预算约束；复用前重新核实有效性，暂停、取消、到期或真实变更时丢弃。
- 优先分析已到期的原生 Live Photo，每最多八项后给普通项目一次优先机会，减少配对目标被普通项目积压。未来重试仍等待原定期限，未核实目标仍不能用于配对。
- 正常排队和资源占用不再表现为故障恢复；真正的读取排空、停滞、故障重试和暂停仍保留保护与提示。沿用六种状态、每任务一行说明和同宽纯色进度条。
- 日志补充排队、请求准备、系统下载进度、保留/复用/丢弃结果，继续匿名聚合和限量明细。下载达到 100% 不等于读取完成，仍以终止回调和资源验证为准。

未知历史变更仍重新核实：公开 API 无法可靠证明历史通知与已处理的实时通知是同一次变更。生产读取保持串行；合成的一路/两路实验不证明实际 iCloud 并发收益。

不改变 schema v11、10 秒普通视频筛选、精确配对、原资源及音轨保留、未知写入保护、来源只读和已批准的单项替换删除规则。

## 验证与分发

开发证据见 [beta6 验证记录](../validation/2026-10-23-beta6-live-photo-continuation.md)。完整开发验收通过后本地 squash 合并到 main；发布从该确切提交归档运行 `scripts/package-release.sh --scale-profile full`。门槛包含完整 XCTest、Tools、四档规模、两组续体竞争，以及版本、Universal、图标、签名、DMG、源码清单和校验值核验。仅随包新生成的通过证据确认发布成功。

原生 UI 验证使用隔离模型，涵盖一项/两项任务、已知/未知总量、等待、暂停和详情弹窗；不等同于系统菜单的物理 hover、键盘或 VoiceOver 验收。未修改 Photos 提交路径，未执行新的真实图库写入；系统进度回调的真实 iCloud 频率、实际吞吐和 macOS 13/14、Intel 实机仍需运行验证。

交付目录 `outputs/releases/0.3.0-beta6/`，已有目录拒绝覆盖。未执行生产 App 安装/重启、远端发布、Developer ID 签名或公证。
