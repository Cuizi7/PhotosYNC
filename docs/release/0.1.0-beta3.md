# PhotosYNC 0.1.0 beta3

PhotosYNC 0.1.0 beta3 (build 3), macOS 13+, Universal arm64/x86_64.
本包为本地 ad-hoc 签名版本，未作 Developer ID 签名或公证。
保留 schema v3、源只读和 Photos 只增不删；不修改现有成功历史，不自动重判历史跳过记录。

## 修复

1. 扫描发现源属性变化时，不再覆盖正在导入记录的身份、attempt 或 placeholder；已经提交的成功结果仍能落库。正常并发状态变化不会误停整个同步引擎。
2. 文件明确未提交后的重试期限由 runtime tick 消费，不必等到下一次 30 分钟周期扫描；暂停、停用和未知提交阻断仍生效。
3. 目录完整遍历恢复后独立清除目录故障；单个坏文件继续单独提示，不再让整个来源看起来离线。
4. deferred 正常等待显示“稍后继续”，不再同时宣称“已完成”；pending、重试和未确认提交分别展示。
5. 文件问题与来源不可用按类别展示；健康兄弟项仍在处理时显示正在同步，真实目录不可用继续优先显示等待恢复。

补充调整：日志按来源/阶段/文件去重，目录恢复后故障重现重新记录；停用来源可直接启用并复用身份/历史，操作中防止重复动作；长菜单信息区滚动且操作区固定。EXIF 与视频日期拒绝非法日历日期，合法带 offset 的视频小数秒保留其整数秒，避免浮点进位；不增加判重容差或猜测时区。

## 边界与未验证项

此补丁不自动重判历史 skipped，也不能修补过去已经丢失的成功历史。没有数据库迁移或生产数据清理，不增加内容哈希、挂载身份跟踪、自动挂载、照片删除/覆盖或图库修复。

本轮没有启动生产应用、读取或写入真实 Photos、扫描生产来源、更改通知或登录权限、安装应用。原生菜单/设置交互、键盘/VoiceOver、真实 PhotoKit 和网络故障、macOS 13/14 实机、系统通知/登录启动没有在 beta3 重新验收；历史验证见 `Design/Validation.md`，不能视为本包的新验证。

真实视频经 AVFoundation 提取带 offset 小数秒尚未验收，当前证据为解析器及自制 JPEG 元数据提取测试。已有来源通知标题仍统一使用“PhotosYNC 来源等待恢复”；这是本轮范围外的文案观察，正文与 UI 分类不受此说明替代。

## 发布验收闭环

后续本地构建由 `scripts/package-release.sh` 强制在同一已提交源码归档中执行完整 XCTest、合成数据工具测试及已纳入版本控制的续体竞态回归，全部成功后才进行正常 Universal Release 构建和验包。失败、零测试、超时、旧发布路径或发布锁冲突都会停止，不支持跳过测试或覆盖旧包。

AppModel 操作与离屏布局已加入常规 XCTest；具体测试数量及源码提交以每个包附带的验证证据和 provenance 为准。原 1f0047d 包的历史验证记录保留，不表示它曾通过后来新增的门槛。普通 beta 可复用未变更系统边界的历史真实 Photos 验收；改变系统集成边界时按 AGENTS.md 做针对性验证。
