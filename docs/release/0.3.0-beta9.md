# PhotosYNC 0.3.0 beta9

版本：0.3.0 beta9（build 26），最低 macOS 13，Universal arm64/x86_64；本地 ad-hoc 签名 App / DMG。

## 修复

- 冷启动准备候选时，安全的来源枚举可以先推进。真正导入仍需有效候选快照，未知 Photos 提交继续阻断新写入。
- 完整 Live Photo 已验证、且全部冻结资源精确覆盖旧尝试时，结算确定未提交或失败的旧待办，避免任务残留在“等待恢复”。保留未知创建/删除和资源变化保护。
- 数据库短暂 BUSY/LOCKED 在同一 runtime/store/gateway 中按期限恢复，覆盖初始化、来源加载和晚到配置绑定。保留统计与成功证据，修正把短暂锁误判为永久停摆及矛盾错误提示的问题。

## 已知问题

**设置页错误文字偶发倒置仍未复现，尚未修复。** 当前原生窗口矩阵中的文字正立，不代表该偶发问题已经解决。

## 升级及验证

沿用 schema v12，不清空成功历史或首次识别完成标记；本版没有新的 schema 升级。启动后仅对上下文与精确覆盖证据成立的旧待办自动结算。按通常方式退出旧应用后替换 App；打包不安装或启动应用，不修改生产图库、数据库或来源。

从合并后 main 的确切提交执行 `scripts/package-release.sh --scale-profile full --ui-profile native --ui-allow-focus`。包含完整 XCTest、Tools、四档规模、两组续体竞态、真实 Settings/MenuBarExtra 的54帧审阅，以及正常Universal构建、版本、架构、图标、逐层签名、DMG与校验值检查。原生验收仅运行隔离QA和fake Photos。

开发阶段证据与可复制命令见[本轮验证记录](../validation/2026-10-24-portable-test-strategy.md)及[测试说明](../testing/README.md)。最终发布结果以随包 `PhotosYNC.provenance`、`validation/validation.json` 和 `SHA256SUMS` 为准；旧提交的通过标记不替代本包验收。

真实生产图库升级、PhotoKit/iCloud、第二台Mac、macOS13/14、Intel与1×显示器没有本轮新增实测。产物为ad-hoc签名，未做Developer ID签名或公证。

交付目录：`outputs/releases/0.3.0-beta9/`。沿用现有beta的本地发行方式，不覆盖旧包，不推送远端或公开发布。
