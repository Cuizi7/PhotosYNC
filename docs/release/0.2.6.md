# PhotosYNC 0.2.6

版本：0.2.6 stable（build 14）。最低 macOS 13，arm64/x86_64 Universal。实际源码提交、完整验证及产物身份见随包的 `PhotosYNC.provenance` 与 `SHA256SUMS`。

## 本版修复

- **Photos 请求同步启动卡住时保持逻辑响应。** 将同步 request 启动移到 utility 队列，逻辑超时、取消和 reader 接纳查询不再等待该同步调用返回。仍由原单一 active owner 限制实际工作，超时或重复 tick 不会启动替代读取来绕过它。
- **保留物理资源的双门槛。** 只有启动调用已返回、终止及关闭/解码处理也已结算，才允许物理所有权转移或释放。系统同步回调早于启动返回、取消句柄晚到和重复终止都保留同一份资源及取消约束。

这是由隔离受控反例确认的条件性 R1 修复。永久不返回的系统启动仍会占用有界 worker、owner 和资源预算；本版不能强制终止系统调用，也不保证此时继续读取健康兄弟项。

**本版不代表已解决现场 Photos 超时、超时后的长时间物理清理等待，或来源视频元数据错误。** 这些现场问题的底层原因仍未确认，不能由本次自动回归推断已修复。

## 升级与验证边界

继续使用 schema v9，不增加迁移、不清理或重判历史。模型、0.98 阈值、资源选择与解码、来源只读、Photos 仅新增、成功导入及 unknown 提交保护沿用现有规则。

修复已通过三项持久 RED/GREEN 回归和独立复核。正式发行从最终干净 main 提交归档执行完整无过滤 XCTest、工具测试、两条受控续体回归、模型/资源及 full 四档规模验收，再进行正常 Universal Release 构建、逐层签名和 DMG/校验值核验。实际结果由本次随包证据记录，不以历史测试替代。

新 utility 执行上下文仅经 fake requester/lifecycle 自动测试；未新做真实 PhotoKit、iCloud、GUI、系统授权或 macOS 13/14、Intel 实机验证。此次发布不安装、替换、重启或启动生产应用，不操作生产照片、同步目标或数据库。

公开资产为 `PhotosYNC-0.2.6.dmg`、`PhotosYNC.provenance`、`RELEASE-NOTES.md`、`SHA256SUMS`；公开校验文件覆盖前三个载荷。本地完整验收及完整校验清单单独保留。
