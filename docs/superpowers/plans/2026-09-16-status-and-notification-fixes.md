**状态：代码与隔离测试已完成，待发布打包及单独的生产部署授权。** 目标版本 0.1.0 beta2（CFBundleShortVersionString=0.1.0，CFBundleVersion=2，显示渠道 beta2，标签 v0.1.0-beta2）。实施保留 0.1.0 beta 冻结标签或安装包。

**目标：** 非导入候选不进入检查/跳过统计；已导入数量跨扫描和重启保持可解释；通知权限恢复后清除对应错误；提示内容与问题类型匹配。

**技术范围：** Swift/SwiftUI、SyncEngine、SyncStore、AppModel、StatusMenu、现有 XCTest。保持 macOS 13、源只读、Photos 仅新增、保守判重及成功历史保护。实施使用独立修复分支，保留冻结产物。

## 根因与证据

- SyncEngine.scan 每轮清零 checked/imported/skipped/failed；pending 来自持久化队列，已经混合两种口径。
- scanSource 在分类之前递增 checked；非 image/video 进入 non_media_skip 并递增 skipped。
- 已有 file_record 的属性未变时直接 continue；已有 imported/skipped 不被汇总。本轮新增成功为 0 不表示历史未导入。
- 当前已读取的生产快照：活动来源有 115 imported、1 suspectedDuplicate；另有 114 RAW、26 sidecar。已移除测试来源另有 2 imported 和 README，不能混入当前来源统计。快照会随生产自然运行变化，不能当作固定测试数据。
- AppModel.setNotifications 授权成功不清除之前 error；系统设置外部授权没有刷新逻辑。
- StatusMenu 只要存在任何 detail 就显示 Photos 提交不确定/检查点风险文案，通知错误也被错误套用。

## 建议统计契约

### 当前启用来源的同步状态（数据库汇总）

独立显示：已导入、已跳过、待处理、提交中/待确认。汇总仅覆盖 enabled=1 AND removed=0 的来源，避免历史测试目录污染。

- 已导入：file_record.state=imported 的记录数，跨扫描、跨应用重启读取，不是本轮成功回调次数。
- 已跳过：受支持媒体中，因疑似重复、源发生变化等规则而 state=skipped 的记录数。
- 待处理：state=pending；需要重试的错误另外提示，不将它重复计入另一互斥状态。
- 提交中/待确认：state=importing，按实际执行/恢复信息显示合适文案；不能误报成功或无待处理。
- non_media_skip 完全不参与用户的候选/跳过汇总。
- 汇总是已登记记录的状态，不宣称是源目录实时文件总数；文件删除后成功历史仍保留。sourceChanged 的成功历史继续用于防重，但当前状态计入已跳过，不在两个状态重复计数。

### 本轮扫描（单独一行）

统一显示“本次扫描：检查 N 个候选 · 新增导入 M”，指正在进行或最近一次结束的扫描；另外标注进行中、完成或中断及时间。未开始时显示“尚未扫描”，不可用初始化 0 冒充完成结果。

- 检查仅包括扩展名分类为 image/video 的候选；每轮同一路径只计一次，已有 imported/skipped 仍属于该轮被检查的候选。
- “候选检查”包括属性核对，不声称重新读取了每张的完整元数据或做了内容哈希。
- RAW、XMP、其他明确不支持文件不检查、不跳过，日志可保留忽略分类。
- 支持格式的损坏文件/元数据读取失败仍是错误，不转成忽略。
- 目录枚举失败等无法确定候选数量的错误单独提示，不能伪造候选；错误数不是互斥文件状态，不能要求与状态汇总相加等于 checked。
- 对恢复成功/上轮延迟返回的提交，不算成本轮新导入；按提交所属轮次更新，累计状态始终由数据库读取。测试覆盖跨轮回调，不靠随机 sleep。

以当前快照、下一轮源内容不变且扫描正常完成为例：

```
已导入 115 · 已跳过 1 · 待处理 0
本次扫描：检查 116 个候选 · 新增导入 0
```

存在 importing 时另显示其数量。不要把 115 历史成功改写为本轮新增 115。

## 任务 2：通知错误生命周期与针对性提示

- [ ] 写失败回归：拒绝→应用内授权成功；拒绝→系统设置外部授权→刷新；通知开关关闭；查询暂时失败。
- [ ] 通知权限/请求错误从通用 error 分离为独立通知状态，不能通过匹配英文字符串判断来源。
- [ ] 授权成功或用户关闭应用通知开关时只清通知错误，不清 Photos、来源、存储、登录项等其他错误。
