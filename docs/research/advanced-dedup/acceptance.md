## Reproducible gate and boundaries

`research.py accept --protocol PATH --dataset PATH --results PATH --output-dir PATH` requires an approved protocol, byte-verified dataset, separate calibration and sealed score reports, model package, candidate profile, public regression report, conversion report, and three-scenario real-media performance report. The results JSON names each as `{ "path": "/absolute/path", "sha256": "..." }` under `profile`, `model`, `calibration`, `sealed`, `publicRegression`, `conversion`, and `performance`, plus `calibrationFrozenBeforeSealed: true`. Produce calibration and sealed scores separately with `research.py score --split calibration|sealed` against the same dataset manifest. Each split builds one shared exact-index catalog from **every audited distractor** plus that split's required candidates; distractor rows need explicit representation and positive dimensions. The saved catalog is byte-bound and reconstructed from the dataset at acceptance, and the same Swift scorer reruns every query against it. The public 44 cases retain their frozen per-case galleries; their requests and decisions are likewise reconstructed and rescored. Legacy R2 manifests without each vector's byte SHA256 fail closed. The gate rejects a wrong `skip` for any sealed expected-import query, even in a positive or retrieval stratum, while retaining the approved copy-recall target and allowing benign extra imports. It checks one prespecified query per sealed group/hypothesis, 540 distinct positive groups, 100,000 distinct audited distractor original identities (edited representations do not multiply assets), exact confidence bounds, and measured budgets. Performance evidence must bind the CPU-only model, fingerprint and profile and provide at least 20 raw query/update times per scenario; the gate recomputes both P95s. A passing configuration must deserialize as the shared Swift `DedupConfiguration`. A result with synthetic performance provenance is rejected. Its accepted ID is SHA256 of the 32 protocol-hash bytes followed by the 32 sealed-result-hash bytes; `accepted-profile.json` contains this ID, and `acceptance.json` binds the final profile SHA256 without a hash cycle. The current candidate has no `accepted-profile.json` or `acceptance.json`.

Weight redistribution permission remains unverified; local conversion is distinct from permission to ship weights. The historical all-compute-units Core ML crash/GPU path remains unresolved; current measurements are CPU-only. macOS 13, Intel/Universal execution, real PhotoKit/iCloud reads, authorization, production catalog behavior, and full-app memory/latency remain unverified. This research outcome does not authorize product integration, release, signing, installation, or production Photos/database access.
