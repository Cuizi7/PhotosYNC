# 来源同步

## 输入与判重

- 支持位图照片与视频；RAW、旁车等非候选不进入进度或 skipped。支持格式的必需元数据读取失败是文件错误，不能假装缺少 metadata 或绕过解析导入。
- 来源严格只读：不改写、移动、删除、转码、暂存原片或计算原文件哈希。导入原 URL，`shouldMoveFile = false`。不跟随根目录、祖先或子项符号链接；仅规范化已核实的系统 `/var`、`/tmp` 别名。
- 多来源使用同一路径；不自动挂载、保存网络凭据或映射相册。停用/移除保留历史；重加同一路径恢复原来源身份。停用来源仍参与目录重叠检查。恢复只核对路径可枚举，尚未验证卷/共享身份；断挂后残留空目录可能被当作可用。
- 照片使用[视觉判重](visual-index.md)；视频按含扩展名、区分大小写的完整文件名比较。只有可靠拍摄秒值不同或完整相机信息明确冲突才能排除同名候选；不猜时区、不加时间容差。未知信息不能证明不同。
- Photos、有效本地排队项和成功历史都参与候选；跳过本身不是成功证据。成功导入即使目标后来被删也不自动补导；源 size/mtime 变化走 `sourceChanged`，未变也不是内容校验。

## 枚举与提交

1. 每个文件夹完成直属枚举及有界 Live Photo 身份识别后放行；子目录独立。跨目录配对需两边就绪，历史 pending/retry 也不能绕过。
2. 冷启动根目录尚未成功枚举或已失联时，关闭该来源的新读取/提交。恢复期限到了不等于根已恢复；晚到的旧成功不能重开被暂停/停用/较新失败关闭的准入。
3. 子项失败时有界复核根目录：根正常则隔离坏文件/子目录，健康兄弟继续；根失败只报根故障；复核 busy/超时只是 deferred。其他来源与图库分析继续。
4. 提交前持久化意图，再使用唯一 Photos 槽位；每次 await 后重核来源、暂停、版本、候选和目录准入。暂停停止新工作，已发请求仍需结算。

## 持久化与恢复

| 文件状态 | 含义 |
| --- | --- |
| `pending` | 待提交；有 `last_error` 的明确未提交项单独计为 retryPending |
| `importing` | 意图/在途/结果未知；placeholder 不代表成功 |
| `imported` | 明确成功，历史永久保留 |
| `skipped` | 有原因的未导入，不伪造成功关系 |

Photos 与 SQLite 无联合事务。超时、崩溃、权限不足、一次查不到均不能证明未提交；只有明确未提交证据才可重试。先保存成功回调事实，再补查询或日志；unknown 阻断所有新 Photos 写入。

只有完整、非暂停/非 deferred 的目录遍历能确认来源文件消失。仅移除从未提交或明确未提交的 pending 及其候选证据，并重判依赖它的跳过项；importing/unknown/成功历史不动。目录项类型都未读到时不能推断后代删除。

## 调度与计数

启动与每 30 分钟扫描；手动扫描立即请求，不叠加扫描、不补跑休眠期间积压。三条曲线独立：

| 情况 | 延迟（秒） | 影响 |
| --- | --- | --- |
| 来源不可用 | 5 / 15 / 30 / 60 / 300 封顶 | 只暂停该来源，成功完整遍历后清除恢复状态 |
| 文件明确未提交失败 | 5 / 15 / 30 / 60 封顶 | 只重试该文件；扫描元数据失败由后续扫描再发现 |
| busy / 逻辑超时 / 暂无容量 | 5 / 5 / 15 / 15 / 60 封顶 | 正常 deferred，不增失败、retry 字段或通知 |

持久统计只计启用且未移除的来源；退役成功另记 `retainedImported`。本轮扫描事件与持久数量分开，不能相加。目录故障不计文件失败；同一问题按稳定身份去重，部分恢复不清除兄弟故障。完整遍历前不能用“诊断项已经为空”宣称来源恢复。
