## 展示契约

| 情况 | 标题 | 小字／进度 |
| --- | --- | --- |
| 视觉索引或历史识别正在工作 | 正在准备 | 正在建立视觉索引／正在配对 Live Photo，各自计数 |
| 来源正在扫描／提交，或配对正在补齐 | 正在同步 | 真实来源进度；配对进度独立 |
| 全部未完成工作均在等资源、退避或未知写入结果 | 等待恢复 | 可恢复原因及 hover 诊断 |
| 用户暂停 | 已暂停 | 保留结果与进度 |
| 缺少权限、阻断错误或需要主动处理的项目 | 需要处理 | 明确问题和可执行操作 |
| 没有未完成工作，正常等待下次扫描 | 同步完成 | 保留独立历史统计 |

缺权限和阻断错误优先，其次用户暂停、未知写入安全等待；其余根据真实活动投影。一个来源失联不会遮蔽其他正在推进的工作。下载、保存和数据库阶段不独立成为用户状态。失败不计入已分析分子；总量未知时不生成总百分比；已验证但保护性保留的单项不算持续待清理。

## 系统与分发边界

本轮只使用合成媒体、UUID 临时库和 fake；没有启动生产 App、读写生产库、扩大真实 Photos 写入范围或执行真实 iCloud-only 原件下载。只读云端验收仍需选定可确认仅在云端的受控资产、工具身份和流量上限后再执行。既有 beta1 私人素材及限定 QA 均保留在忽略目录，不提交或打包。

未新增 macOS 13/14 或 Intel 实机验收、真实系统菜单／键盘／VoiceOver 验收；不以离屏图像替代上述事实。发行使用既有本地 ad-hoc 签名与 DMG 流程，不含 Developer ID、公证、安装或公开远端发布。
