## 原生 UI

假状态与 UUID 临时数据库驱动实际 SwiftUI/AppKit 设置视图，不启动生产 runtime、不访问真实图库。默认 2 GiB 和自选 4 GiB 的浅深色文案检查通过。最终原生矩阵包含 234 张截图；已核对说明删除、控件、用途说明和 30 来源布局，无可见截断。证据位于 `work/visual-memory-limit/native-ui-final/` 和 `remove-boundary-qa.md`。

这些是编译视图的离屏位图，不是系统合成器截图，也不证明下拉操作、键盘、VoiceOver 或旧平台实机行为。用户已审核渲染图；系统开关在隔离宿主中禁用。
