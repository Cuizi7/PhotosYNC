Base: beta5 `aefe7b2`. Scope: bounded continuation of completed reads and partial observations, native-candidate priority, normal queued activity and anonymous resource telemetry. No production app, database, Photos library or source mutation was performed.

## Reproduction and focused checks

- Classification deferral: two controlled RED tests failed four assertions for repeated raw requests/metadata inspection and released pending bytes. The fix retains one completed raw lease and one partial asset, with 30-second monotonic expiry. Known/unknown changes, context, descriptor, commit-time validity, pause and expiry remain checked.
- Cross-budget reuse: one RED test failed two assertions; a retained resource now requires the same budget owner, so a smaller caller budget cannot be bypassed. The Task 1 run passed 81 tests.
- Native priority and activity: five RED tests failed seven assertions for selection order and normal busy states. Native preference, ordinary fairness, future retry deadlines, completion-only busy work and runtime backoff passed in the 165-test Task 2 run.
- Download telemetry: initial diagnostics RED failed six assertions; a progress-callback probe separately failed six assertions before hookup. The implemented test delivers 1,002 valid updates plus malformed values, verifies constant-size aggregation and confirms that progress 1.0 cannot complete the read or release physical ownership. Late callbacks are ignored.
- Cancellation on retained reuse: one late RED test proved that cancellation during resource validation could return bytes. An additional cancellation check before return/re-retention fixes this. The telemetry/cancellation Core run passed **253 tests, zero failures** (`work/beta6/late-boundaries-green-tests.log`), including resource, inventory, gateway, same-revision/history and index coordinator contracts.
- Integrated review found that parsed observations expired only when the worker ran again. A controlled RED failed two expectations for independent scheduling/release. The coordinator now uses a weak, cancellable timer guarded by the retained identity and original deadline. No further worker call is needed to release tickets; pause cancels the timer. The affected Core/runtime run passed **134 tests, zero failures** (`work/beta6/review-expiry-green-tests.log`). The first full validation attempt was stopped after its build succeeded so the fix could be included; its interrupted XCTest run is not passing evidence.

These selected checks are not the complete release gate. The commit-boundary test checks transactional rollback directly; post-parse continuation is covered separately. It is not a single end-to-end coordinator test that injects a change inside the final SQLite commit.

## Public API limits and controlled experiment

Checked Xcode 27.1 / Swift 6.4 / macOS 27 SDK headers. `PHChange` has object/fetch change details but no persistent transaction identity. `PHPersistentChange` has a token and inserted/updated/deleted ID sets; the token represents library state. No documented shared event identity safely joins these streams. Accordingly, unknown history still invalidates the affected results; equal descriptors or revisions are not content proof. This is an API-based conclusion, not a claim that historical replay can never be optimized.

References: Apple [persistent changes](https://developer.apple.com/documentation/photos/phpersistentchange), [persistent tokens](https://developer.apple.com/documentation/photos/phpersistentchangetoken), [resource progress](https://developer.apple.com/documentation/photos/phassetresourceprogresshandler) and [request options](https://developer.apple.com/documentation/photos/phassetresourcerequestoptions). The progress callback reports iCloud download progress independently of request completion. The new hook uses that public API and never changes resource-validity or completion decisions.

An isolated fixed-delay requester processed the same eight 512 KiB resources in three paired rounds: median 1,536.2 ms with one lane and 763.5 ms with two. Observed physical occupancy was 1/2 and peak owned bytes 512 KiB/1 MiB; all terminal counts and final budgets matched. A cancellation probe retained physical ownership until its delayed terminal callback. The experiment used synthetic data, no Photos/iCloud, and a frozen Task 1 reader snapshot. It validates bounded ownership, **not real-cloud speedup**. Production remains serial. Raw experiment output stays under ignored `work/beta6/read-experiment/`.
