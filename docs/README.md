## 当前未解决

- **Live Photo 已处理数回退：** 重启回放历史 updated ID 会作废对应识别结果并重新排队；首次识别的完成标记没有被清空。视觉索引的成功日期复用不覆盖这条路径，也不能直接作为删除旧单项的内容证明。现有 R01 冷启动测试未覆盖“已识别结果 + 历史更新回放”。
- **设置页错误文字偶发倒置：** 尚未复现、未修复。原生 UI 矩阵通过不代表该现场问题已解决。

## 文档维护

当前规则只在对应主题页维护一份；修改行为时同步更新规则与回归测试。已完成的 spec、计划、研究和验收流水不再另存 Markdown，历史用 Git 查询；发布变化只写 changelog。尚未实现的提议不能混入当前契约。

`docs/research/` 保留被构建和测试直接使用的 JSON、样本结果等机器输入；素材许可留在 [fixtures](../Tests/Fixtures/AdvancedDedup/README.md)，不能当作冗余文档删除。
